# 音乐模块更新说明（SD + FATFS + ES8388）

## 1. 本次更新目标

将音乐播放链路打通为：

1. SD 卡存放音乐文件（WAV）
2. FATFS 挂载并扫描目录
3. 通过 ES8388 + IIS 输出到喇叭

当前主流程已实现：上电初始化 -> 挂载 SD 文件系统 -> 扫描 `0:/MUSIC` -> 按下 `KEY1` 播放第一首 WAV。

---

## 2. 相关文件

### FATFS 适配层

- `code/fatfs/diskio.c`
  - 将 FatFs 的 `disk_*` 接口映射到 `sd_simple_*` 驱动。
  - `disk_initialize()` 调用 `sd_simple_init()`。
  - `disk_read()/disk_write()` 调用 `sd_simple_read()/sd_simple_write()`。

- `code/fatfs/ffconf.h`
  - 关键配置：
    - `FF_USE_LFN = 1`（开启长文件名）
    - `FF_FS_EXFAT = 0`（当前不支持 exFAT）
    - `FF_VOLUMES = 1`（单卷）

- `code/fatfs/ffunicode.c`
  - 配合 LFN 的字符处理文件（已纳入工程编译）。

### 音乐播放模块

- `code/es8388/music_player.c`
- `code/es8388/music_player.h`

功能包括：

1. `music_player_init()`
   - SD 初始化
   - `f_mount()` 挂载 `0:`
   - ES8388 初始化
   - IIS 初始化

2. `music_player_scan_folder(path, &count)`
   - 扫描目录中的 `.wav/.WAV` 文件

3. `music_player_play_first_in_folder(path)`
   - 扫描后播放第一首

4. WAV 解析
   - 支持 RIFF/WAVE
   - 支持 `fmt` / `data` 分块扫描
   - 支持 16-bit、24-bit
   - 支持单声道、双声道

### 主程序入口

- `user/cpu0_main.c`
  - 已接入 music_player 初始化、扫描与按键播放。
  - `KEY1` 触发播放 `0:/MUSIC` 下第一首 WAV。

---

## 3. 使用方式（最小步骤）

1. 将 SD 卡格式化为 **FAT32**（不要 exFAT）
2. 在 SD 卡根目录创建文件夹：`MUSIC`
3. 拷贝 WAV 文件到 `MUSIC`
4. 上电后观察串口
5. 按 `KEY1` 播放

建议先使用：

- 采样率：44.1kHz
- 位宽：16bit
- 声道：单声道或双声道
- 文件名：先用英文，避免路径编码问题

---

## 4. 串口日志与问题定位

### 正常典型日志

- `[SD] card available.`
- `[MUSIC] init ok, scan folder 0:/MUSIC ...`
- `[MUSIC] scan ok, wav count=...`
- 按键后：`[MUSIC] key1 pressed...` / `key play ret=0`

### 常见错误码

#### `music init failed, code=1`

- 含义：`sd_simple_init` 失败
- 排查：SD 卡硬件连接、SPI 引脚、电源、卡本身

#### `music init failed, code=2`

- 含义：`f_mount` 失败
- 常见原因：
  - SD 卡未格式化为 FAT/FAT32
  - 文件系统损坏
  - 读扇区不稳定

#### `music init failed, code=3`

- 含义：`es8388_init` 失败
- 当前已加入 I2C 详细探测日志和诊断入口，按日志定位引脚/地址/硬件问题

---

## 5. 当前设计说明

1. 音乐模块支持“先挂载再播放”，避免上电直接长阻塞。
2. 采用目录扫描缓存文件列表，便于后续扩展“上一曲/下一曲”。
3. `cpu0_main` 中由按键触发播放，串口可直接观察返回码。
4. 目前以 WAV 直接播放为主，不包含 MP3 解码。

## 7. 注意事项

1. 本工程当前未开启 exFAT，建议统一 FAT32。
2. SD 卡插拔后建议重新上电或重新初始化。
3. 若日志显示 sector0 末尾不是 `0x55AA`，优先检查文件系统与读卡稳定性。
4. 若出现 ES8388 I2C 无 ACK，先确认电源、地、SCL/SDA 连线与地址脚。
